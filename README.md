# ZENITH Dashboard

Zenith is a high-density, privacy-first financial command center designed for individuals who demand absolute data sovereignty and professional-grade financial intelligence. Built on an obsidian-minimalist aesthetic, Zenith transforms personal finance into an executive engineering discipline.

---

## 🛰️ Core Philosophy & Services
Zenith operates on the principle of **Data Sovereignty**. Unlike traditional financial tools, Zenith does not utilize cloud synchronization or third-party data harvesting.

- **Local-First Architecture**: Your financial ledger is stored exclusively within your browser's persistent node. We never see your balances, transactions, or identity.
- **Zero-Cloud Dependency**: No external database uplinks. Your data is your own, secured by the AES-256 standard and local authentication protocols.
- **Wealth Engineering**: Beyond simple tracking, Zenith provides tactical tools for Debt Management (Loans), Asset Nexus (Investments), and Strategic Objectives (Goals).

---

## 🧭 Operational Routes
The terminal is mapped across several strategic nodes to provide a comprehensive financial overview:

### Public Nodes
- **` / ` (The Terminal Entrance)**: A premium hero experience detailing the Zenith protocol and core benefits.
- **`/onboarding` (Node Initialization)**: A multi-step sequence to establish your personnel profile, bank nodes, liabilities, and objectives.
- **`/login` (Personnel Restoration)**: Securely restore your terminal access using a tactical backup file (.JSON) and identity verification.
- **`/terms` & `/privacy`**: Standalone legal documentation decoupled from the dashboard for clear, static review.

### Command Center (Authenticated)
- **Dashboard**: The Executive Command Center. A high-density summary of your financial ecosystem, net worth, and tactical cash flow.
- **Ledger (Transactions)**: A precise tracking node for Income, Expenses, and Transfers with advanced filtering and search capabilities.
- **Intelligence (Goals)**: Strategic roadmap for long-term objectives with AI-driven performance tracking.
- **Insights (Reports)**: Analytical deep-dives into spending patterns, heatmaps, and categorical distribution.
- **Personnel (Profile)**: Configuration node for identity management, security protocols (PIN/Questions), and currency localization.

## 🛡️ Security & Privacy
- **Vault-Grade Storage**: Data persists localized to your hardware.
- **Personnel Restoration**: Manual backup/restore via JSON ensured portability without central risk.
- **Self-Custody**: You are the sole administrator of your financial nodes.

## 🏁 Getting Started
1. **Initialize**: Clone the repository and navigate to the root directory.
2. **Deploy**: Run `npm install` followed by `npm run dev`.
3. **Personnel Onboarding**: Access the dashboard and follow the "Node Initialization" steps to begin your wealth engineering journey.
